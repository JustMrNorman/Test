## Выделение текста

| Стиль | Синтаксис | Результат |
|---|---|---|
| Курсив | `*текст*` или `_текст_` | *курсив* |
| Жирный | `**текст**` или `__текст__` | **жирный** |
| Жирный курсив | `***текст***` | ***жирный курсив*** |
| Подчёркнутый | `<u>текст</u>` | <u>подчёркнутый</u> |
| Зачёркнутый | `~~текст~~` | ~~зачёркнутый~~ |

## Списки

### Маркированный

- Первый пункт
- Второй пункт
  - Вложенный пункт
  - Ещё один вложенный
- Третий пункт

### Нумерованный

1. Первый
2. Второй
   1. Вложенный
   2. Ещё вложенный
3. Третий

### Чек-лист (расширение GitHub)

- [x] Выполненная задача
- [ ] Невыполненная задача

## Вставка кода

### Инлайн-код

Чтобы установить пакет, выполни `npm install` в терминале.

### Блок кода без подсветки

```
просто текст
без подсветки синтаксиса
```

### Блок кода с подсветкой

```bash
git add .
git commit -m "Первый коммит"
git push
```

```python
def hello(name):
    print(f"Привет, {name}!")
```

```javascript
const greet = (name) => console.log(`Привет, ${name}!`);
```
